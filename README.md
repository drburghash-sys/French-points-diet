# ميزان النقاط — الرجيم الفرنسي (تقديري)

تطبيق ويب عربي متجاوب (PWA) مستقل عن «خطوتي» (Wo) ويحتفظ بالهوية الزمردية. جميع بيانات المستخدم تحفظ محليًا في المتصفح.

**الموقع:** https://drburghash-sys.github.io/French-points-diet/

## الإمكانات

- **869 صنفًا مضمّنًا للعمل دون الإنترنت:** 450 من بيانات USDA العامة مع 1300 حصة منزلية، و419 صنفًا عربيًا ومحليًا تقديريًا من الأطباق السعودية والسندويتشات والوجبات السريعة والصوصات والحلويات والبسكويت.
- بحث عربي/إنجليزي، تصنيف الطعام والمطاعم والصوصات، اختيار كمية بوحدة «حبة، رغيف، طبق، ساندويتش، ملعقة، كوب، فنجان، جرام» مع تعديل وزن الحصة بالجرامات مباشرة.
- مكوّن وجبة: اختيار الأساس + أي عدد من الصوصات والإضافات والمشروبات والجبن، مع تعديل وزن كل إضافة وعدد الحصص وحساب الإجمالي فورًا.
- نقاط وسعرات اليوم، رصيد يومي **يُحسب تلقائيًا من بيانات الشخص أو يُحدد يدويًا**، ملخص أسبوعي، وزن، ماء وحركة دون احتساب الرياضة تلقائيًا على ميزانية الأكل.
- مكتبة شخصية: إضافة وتعديل وحذف أي طعام أو صوص بقيم السعرات والدهون والألياف للكمية المحددة.
- تحويل السعرات والدهون والألياف إلى نقاط وحفظ الحساب كصنف شخصي.
- سجل زمني للوجبات والمكونات الفعلية، تصدير واستيراد نسخة JSON، مظهر داكن، وضع عدم الاتصال بعد التثبيت/التحميل الأول.
- أيقونة أصلية مخصصة بالزمرد والذهبي: `icon.svg`، وملف manifest لتثبيت التطبيق.

## حساب رصيد النقاط اليومي حسب العمر والوزن

يحتوي التطبيق على استبيان تاريخي غير رسمي لنظام النقاط الفرنسي القديم (لا يطابق خوارزمية WeightWatchers الحديثة):

- الجنس وفق الجدول القديم: ذكر 15 نقطة، أنثى 7 نقاط.
- العمر: 18–20 = 5 نقاط؛ 21–35 = 4؛ 36–50 = 3؛ 51–65 = 2؛ 66 فأعلى = 1.
- الوزن بالكيلوجرام: العشرات الصحيحة (مثال: 92 كجم = 9).
- الطول: أقل من 160 سم = 1؛ 160 سم فأكثر = 2.
- حركة العمل واليوم: جلوس = 0؛ جلوس وبعض الحركة = 2؛ غالبًا واقف = 4؛ نشاط شاق = 6.
- الهدف: إنقاص = 0؛ تثبيت = 4.
- مجموع العناصر مع حد أدنى تاريخي 17 نقطة، **وهذا الحد لا يضمن كفاية السعرات أو العناصر الغذائية**.
- تظهر التفاصيل فور إدخال الحقول، وتُعتمد الميزانية عند الحفظ. عند تسجيل وزن أحدث يتحدث الحساب الآلي، مع إبقاء خيار الحساب اليدوي.
- لا تُنقل الحسابات القديمة إلى تلقائي دون موافقة المستخدم؛ يحتفظ التطبيق بأهدافه وسجلاته ومفتاح التخزين السابق.

المراجع: [عرض تاريخي لجدول النقاط الستة](https://fr.vivat.be/sante/weight-watchers-pratique_1775)، [طريقة WW الحديثة](https://www.weightwatchers.com/fr/blog/la-science-et-les-points).

**ملاحظة اختلاف الإصدارات:** توجد أكثر من صيغة تاريخية لحساب نقاط الطعام. التطبيق يحتفظ بصيغته السابقة (السعرات/50 + الدهون/12 − الألياف المقيدة/5)، وقد لا تطابق حسابات الأطعمة في نسخ فرنسية قديمة استخدمت السعرات/60 + الدهون/9. لا تستخدم الميزانية الناتجة على أنها خطة علاجية مضمونة دون تقييم الاحتياج الغذائي.

## الصيغة

تم استخدام الصيغة الكلاسيكية **غير الرسمية**:

`points = max(0, kcal/50 + fat_g/12 - min(fiber_g, 4)/5)`

الألياف تخص حصة الطعام المدخلة؛ عند تكوين وجبة تُجمع القيم الغذائية للمكونات **قبل** حساب نقاط الوجبة. تُعرض النتائج بمقدار عُشر نقطة، ولا تُجبر على التقريب إلى عدد صحيح. الطريقة الكلاسيكية لا تعادل النظام التجاري الحالي WeightWatchers®، الذي يستخدم معلومات غذائية إضافية وحسابات خاصة.

**مهم:** نقاط/سعرات المطاعم والوجبات المحلية وأصناف الشوكولاتة تُعد **تقديرًا تجريبيًا** لا ملصقًا معتمدًا. تختلف أحجام العبوة والوصفات والزيوت والصوصات كثيرًا. استخدم الأرقام المطبوعة على عبوتك عند توفرها، واستعمل الوزن الفعلي بالجرام. لا تضف صوصًا موجودًا أصلًا داخل تقدير الوجبة لتفادي احتسابه مرتين. المرجع USDA يدل على متوسط غذائي وليس بالضرورة منتجًا تجاريًا مطابقًا.

الميزانية الافتراضية (24 نقطة) نموذج إدخال وليست توصية غذائية أو تقديرًا لاحتياج مستخدم محدد. يمكن للمستخدم تعديلها؛ لا يقرر التطبيق خطة تجويع أو علاجًا.

## نشر GitHub Pages

يُنشر تلقائيًا بواسطة `.github/workflows/pages.yml` إذا كانت إعدادات المستودع: **Settings → Pages → Build and deployment → GitHub Actions**. لا يُستخدم خادم أو حساب، ولا تتم مزامنة المشتريات أو الوزن عبر الأجهزة. للعمل دون إنترنت افتح الموقع مرة واحدة أثناء الاتصال.

## هيكل الملفات

## الخصوصية

البيانات في `localStorage` على **هذا الجهاز والمتصفح فقط**. لا تضع ملفات النسخ الاحتياطية الشخصية في مستودع GitHub عام. امسح النسخ الاحتياطية الزائدة وخذ نسخة عند نقل الجهاز. التطبيق لأغراض التسجيل والتقدير فقط ولا يغني عن متخصص تغذية.
